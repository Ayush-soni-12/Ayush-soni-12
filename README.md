## 🚀 Featured Projects

### 🤖 [NeuralControl](https://github.com/Ayush-soni-12/AI_CONTROL_PLANE) — Intelligent Microservice Optimizer

> 🌐 **Live:** [neuralcontrol.online](https://neuralcontrol.online)

An AI-powered control plane designed to **observe microservice behaviour and autonomously make performance decisions** using LangGraph and Gemini.

**Highlights:**

* 🧠 **LangGraph-based AI workflow** built with FastAPI for autonomous infrastructure decisions
* 📊 Analyses **p50 / p95 / p99 latency signals** to determine appropriate actions
* ⚡ Supports intelligent **caching, circuit breaking, load shedding, and rate limiting**
* 📡 **Server-Sent Events (SSE)** stream AI decisions to the dashboard in real time
* 🏢 **Multi-tenant architecture** with isolated metrics and tenant-specific decisions
* 📦 Published npm SDK — `@ayushsoni12/ai-control-plane`
* 🐳 Fully containerised architecture using **Docker Compose**
* ✅ Uses protocol-correct responses including **HTTP 429, 503, and 202**

`FastAPI` `LangGraph` `Gemini API` `Python` `TypeScript` `PostgreSQL` `Redis` `Docker` `SSE` `npm SDK`

An enterprise-style higher-education platform that connects **Students, Faculty, HODs, College Administrators, and Super Administrators** through role-specific workflows.

**Highlights:**

* 🛡️ **Hierarchical RBAC verification** across Student → Faculty → HOD → College Admin → Super Admin
* 📍 **Geofenced dynamic QR + rotating OTP attendance** with server-side Haversine distance validation
* 🤖 **Gemini-powered grievance intelligence** for categorisation, urgency detection, summaries, and automatic routing
* 🔮 **AI attendance shortage prediction** with SAFE / WARNING / CRITICAL risk classification
* 🎯 Interactive **what-if attendance simulator** for students
* ⚡ High-performance batch attendance using **MongoDB bulkWrite**
* 📅 Timetable engine with **faculty substitution, clash detection, and leave workflows**
* 🔔 Real-time notification center for schedule, grievance, and verification events
* ☁️ Integrated **Cloudinary, JWT, Zod, MongoDB, React Query, and AWS-ready architecture**

`Node.js` `Express.js` `React` `Vite` `MongoDB` `Gemini API` `Tailwind CSS` `JWT` `Cloudinary` `Zod`

### 🔐 [neural-auth](https://github.com/Ayush-soni-12/Auth-Package) — Reusable Authentication Package

> 📦 **npm:** `neural-auth`

An enterprise-oriented authentication package for Express applications designed to remove repetitive authentication boilerplate while remaining **extensible and database/cache agnostic**.

**Highlights:**

* 🔑 Complete **signup, login, logout, email verification, OTP, and password recovery**
* 🛡️ Built-in **role-based access control (RBAC)** middleware
* 🔐 JWT authentication with **HTTP-only secure cookies** and token blacklisting
* 🔢 Email-based **two-factor authentication**
* 🌐 Built-in **Google OAuth** authentication
* 🧩 `createUserModel()` allows applications to extend the base user schema
* 🗄️ **MongoDB adapter** with an extensible database adapter architecture
* ⚡ **Memory cache by default**, with Redis adapter support
* 📧 Adapter-based email architecture supporting providers beyond Nodemailer
* 🧱 Custom validation support through **Zod schemas**

`Node.js` `Express.js` `JWT` `MongoDB` `Mongoose` `Redis` `Google OAuth` `2FA` `Zod` `Nodemailer`
