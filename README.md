## 🚀 Featured Projects

### 🏨 [LuxuryStay](https://github.com/Ayush-soni-12/LuxuryStay) — Full-Stack Hotel Booking Platform
> 🌐 **Live:** [luxurystays.site/show](https://luxurystays.site/show)

A production-deployed property listing & booking platform with complex booking logic, Google OAuth, real-time alerting, and full AWS deployment.

**Highlights:**
- 🔐 Google OAuth 2.0 + JWT (HTTP-only cookies) authentication with NGINX-protected admin routes
- 📧 Automated booking confirmations, error alerts via **Nodemailer** + **Telegram Bot**
- ⚡ Performance: **MongoDB indexing**, **Redis caching**, **server-side pagination**
- 🐳 Containerised with **Docker**, deployed on **AWS EC2** via ECR, **NGINX** reverse proxy + **Certbot HTTPS**
- 🗺️ **Google Maps API** integration with address autocomplete
- ✨ **GSAP animations** for smooth UI transitions

`Node.js` `Express.js` `MongoDB` `Redis` `Docker` `AWS EC2/ECR` `NGINX` `Google OAuth` `JWT` `GSAP` `Winston`

### 🤖 [AI Control Plane](https://github.com/Ayush-soni-12/AI_CONTROL_PLANE) — Intelligent Microservice Optimizer

An AI-powered control plane that **autonomously optimises microservice performance** using **LangGraph + Gemini API** — analysing p50/p95/p99 latency signals to make real-time decisions.

**Highlights:**
- 🧠 **LangGraph AI workflow** (FastAPI) for autonomous caching, circuit breaking, load shedding & rate limiting decisions
- 📊 **SSE-based real-time dashboard** — AI decisions stream live, zero polling
- 🏢 **Multi-tenant architecture** with isolated metrics + per-tenant AI decisions (PostgreSQL + Redis)
- 📦 Published **npm SDK** `@ayushsoni12/ai-control-plane` for one-line Express middleware integration
- 🐳 Full stack orchestrated with **Docker Compose** (FastAPI + PostgreSQL + Redis + Node.js)
- ✅ RFC-compliant: HTTP 429 (rate limit), HTTP 503 (load shed), HTTP 202 (queue deferral)

`FastAPI` `LangGraph` `Gemini API` `Python` `TypeScript` `PostgreSQL` `Redis` `Docker` `SSE` `npm SDK`
